# Pocket Play - API

API para a plataforma de jogos Pocket Play

## Tecnologias

- Fastify
- Zod
- TypeScript
- JWT
- Bcrypt
- Prisma
- PostgreSQL
- WebSocket

## Como rodar o projeto

### Opção 1 - Rodando separadamente:

```bash
npm run dev:server
```

### Opção 2 - Rodando todos os projetos:

```bash
npm run dev
```
